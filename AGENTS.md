## Agent skills

### Issue tracker

Issues, specs and tickets live in the repo's GitHub Issues (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Reminders

- **Before running `to-tickets`:** the tracker is GitHub Issues, but this repo
  has no git repo or remote yet. Ask me how to connect to my **public** GitHub
  repo (create a new one, or use an existing one — I'll give owner/name). Then
  create the repo, set the remote, and push **before** publishing tickets.
  If I ask to connect later, draft the tickets first and publish once connected.
